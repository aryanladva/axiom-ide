## 🚀 Quick Start (Build from Source)

### Prerequisites
- [Bun](https://bun.sh) v1.3+
- Node.js v20+

### Installation & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aryanladva/axiom-ide.git
   cd axiom-ide
   ```

2. **Install dependencies**:
   ```bash
   bun install
   ```

3. **Launch AXIOM Desktop**:
   ```bash
   bun run dev:desktop
   ```

- **Deep Space Aesthetics**: Custom dark theme with vibrant neon highlights (`#6d5ef8`, `#3ecf8e`, `#5ba3f5`) and subtle panel glows.
